## The label

> WARNING: Meeting your past self voids the warranty. File claims before you were born.

A deadpan safety notice where the joke is the paperwork: the classic
duplicate-self paradox, told through a warranty clause. Meeting your
past self is a real time-travel hazard — and the bureaucracy's answer
is that your claim had to be filed before you were born. The surprise
lands in the last few words, exactly where a warning label stops being
boring.

## Run it

```sh
node main.ts
```

`main.ts` writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). It uses only the Node standard library,
is fully deterministic — one fixed output, no randomness, no clock, no
network — and writes nothing into the repository.
